Featured projects

Four HTML & CSS builds completed during my program, each solving a different layout and UX problem.

restaurant-site

Local Restaurant Website

Problem it solves

Many small restaurants don't have a simple, mobile-friendly site where customers can view the menu, hours, and location at a glance. This project built a lightweight multi-section site that answers those questions in under 10 seconds of scrolling.

How I built it

design Mapped out a one-page structure (hero, menu, hours, location) and picked a warm, appetite-friendly type pairing.
code Built the menu as a semantic definition list styled with CSS, and embedded a responsive map section.
deliver Ran a Lighthouse accessibility/performance pass and fixed contrast and alt-text issues before shipping.
HTML5 Flexbox Accessibility

personal-blog

Personal Blog Template

Problem it solves

New writers often reach for heavy blogging platforms just to publish a few posts. This project set out to prove a fast, readable blog template could be built with plain HTML/CSS — no framework, no build step, easy to hand-edit.

How I built it

design Prioritized readability: a constrained line length, generous line-height, and a calm two-color palette.
code Structured posts with semantic <article>/<time> tags and a reusable card component for the post list.
deliver Checked heading hierarchy and screen-reader flow, then published as a static template.
HTML5 Semantic Markup Typography

product-landing

Product Landing Page

Problem it solves

A landing page's job is to turn a visitor into a sign-up within seconds. This project practiced that exact problem: a clear value proposition, a pricing section, and a single obvious call-to-action, all above and below the fold.

How I built it

design Wireframed a hero → features → pricing → CTA flow, borrowing conventions users already recognize.
code Built a 3-column pricing grid with CSS Grid, and made the CTA button sticky-visible on scroll.
deliver Cross-browser tested in Chrome/Firefox/Safari and fixed a Safari flexbox gap bug before final delivery.
HTML5 CSS Grid Cross-browser
